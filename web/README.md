# Tripitaka Local — web frontend

This is the React frontend for the Tripitaka.Online local mirror.

See the [root README](../README.md) for the full project, setup and usage.

```bash
pnpm install
pnpm dev        # Vite dev server on :5173 (proxies /api → :8080)
pnpm build      # production build → dist/ (served by the FastAPI backend)
```
